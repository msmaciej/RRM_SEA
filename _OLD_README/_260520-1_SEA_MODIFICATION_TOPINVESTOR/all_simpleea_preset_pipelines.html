PRESET_MA — MT5 Moving Average benchmark
Replicates the built-in MT5 Moving Average EA. Pure price/MA crossover, stop-and-reverse. Zero indicators, zero filters. Baseline for comparing other presets.

All others unused

Indicators

all offZero indicators enabled
VoteMode=ALL (irrelevant — nothing votes)

Exits

BE_MODE_OFF

PRESET_FPM — Five-Point Method
3 indicator votes + bar-close gate, all must align. Simple 2-SMA structure (10+20), no phase detection, no layers. SL/TP/Trail user-controlled.

Architecture

lockedBIAS_2EMA · STRAT_2EMA_POSITION
MaType=SMA · VoteMode=ALL
Phase OFF · Layer OFF

MAs

lockedSMA10 + SMA20
(P_Ema1=10, P_Ema2=20)

Indicators

lockedPSAR (flip+dot) + MACD (crossover ≤5 bars) + BB (widening)
All others OFF

Exits

flexibleSL: Swing (locked) · TP: Fixed pips or R:R
BE: R-multiple at 1R · Trail: Fixed pips (optional)

PRESET_RRM — Phase-based trend pullback
4-EMA phase system with layer detection and recovery gates. Most flexible preset — indicator toggles, SL/TP, trailing all user-controllable. The "standard" RRM implementation.

Architecture

lockedBIAS_4EMA · STRAT_4EMA_LAYER
Phase ON · Layer ON · UNO blocked
VoteMode=ALL

MAs

flexibleInp_RRM_Ema1..4Period
Default: 5 / 13 / 34 / 89

Indicators

flexiblePSAR, MACD, CandleBody, CCI, RSI, ADX, Stoch, BB, MFI, CI, MTF — all toggleable via Inp_RRM_Use_*

Exits

flexibleSL/TP/Trail all user-selected
BE: R-multiple · Trail: PSAR default
Drawdown protection toggleable

PRESET_RRM_ORG — Original Russ Horn RRM with DPI
The most sophisticated preset. Adds DPI v31 momentum voter (inline MACD-core with CCI reset), pullback state machine (P2), phase-age confirmation, EMA fan overextension filter, JPY gate multiplier, and per-layer PSAR flip delays. Quality-first design.

Architecture

lockedBIAS_4EMA · STRAT_4EMA_LAYER
Phase ON + age confirm · Layer ON + pullback SM
EmaFan filter · DPI decel filter

MAs

flexibleDefault: 5 / 13 / 34 / 89
Via Inp_RRM_Ema*Period

Key voter: DPI v31

flexibleInline MACD-core: Blue/Red/Hist
CCI reset, green-hist mode
Per-layer PSAR flip delays

Exits

flexibleSL/TP/Trail user-selected
BE: R-multiple or progress %
DD protection force-ON
TE: BC recheck + open delay
