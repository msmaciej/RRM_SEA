L — Layer pullback → recovery, then the fresh-cross count new

Step 1 — the layer machine (unchanged). Each layer (S 34/89 → M 13/34 → W 5/13, first to pass wins) is a state machine: fast-EMA slope flattens against bias (DETECTED, ≥ 3 bars W/M, 2 bars S) then both slopes resume (IN-TREND). The edge bar is the fire; one entry per pullback.
Step 2 — the fresh-cross count (new). Find the last cross of the layer's reference pair in the bias direction, count the touch-episodes of the layer's EMA since then (the current pullback included). W is the ribbon so its own 5/13 pair flips on every pullback — its clock is the next-slower 13/34 cross; M and S use their own pair. A layer fires only while its count is within the cap.
Step 3 — price confirmation. BC: close beyond the layer's fast EMA (W→EMA1, M→EMA2, S→EMA3 — the Oracle "close past"). BD: bar closed in the bias direction. Progressive momentum over 2 bars.
